### 👾 About Me

> *"First solve the problem. Then, write the code."*

I'm a **Full-Stack Engineer** obsessed with crafting high-performance systems and delightful developer experiences. I bridge the gap between robust backend architecture and pixel-perfect frontend design. When I'm not shipping code, I'm exploring the frontiers of **AI/ML**, contributing to **open source**, or optimizing things that probably didn't need optimizing.

- 🔭 Currently building **distributed systems** that scale
- 🌱 Deep diving into **LLMs, vector databases & MLOps**
- 💡 Passionate about **developer tooling** and **DX (Developer Experience)**
- ⚡ Fun fact: I can debug production issues faster than I can decide what to eat
